COMANDOS PARA COMPILAR E EXECUTAR
=================================

Requisito: GCC instalado (Linux, macOS, Windows com MinGW ou WSL).

1) Clonar o repositório:
   git clone https://github.com/FenyxxDev/atividades-sofia.git

2) Entrar na pasta do projeto:
   cd atividades-sofia

3) Compilar o código-fonte:
   gcc -std=c11 -Wall -Wextra -pedantic ATIVIDADE_ARQUIVOS.c -o streaming

4) Executar:

   Linux / macOS / WSL:
   ./streaming

   Windows com MinGW:
   streaming.exe

Os arquivos videos.bin e usuarios.bin são criados automaticamente
na pasta em que o programa é executado, quando os primeiros registros
forem cadastrados.

Para iniciar com os dados vazios, feche o programa e apague os arquivos
videos.bin e usuarios.bin.

Linux / macOS / WSL:
   rm -f videos.bin usuarios.bin temp.bin

Windows:
   del videos.bin usuarios.bin temp.bin

AVISO: os comandos acima apagam os registros cadastrados.
